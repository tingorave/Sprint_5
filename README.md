# Sprint_5 — UI-тесты Stellar Burgers

Авто‑тесты для учебного проекта Stellar Burgers на Python + Selenium + pytest.

## Функциональность

**Регистрация**

- Успешная регистрация (валидные имя, email, пароль ≥ 6 символов).
- Ошибка при некорректном пароле.

**Вход**

- Вход по кнопке «Войти в аккаунт» на главной.
- Вход через кнопку «Личный кабинет».
- Вход через кнопку в форме регистрации.
- Вход через кнопку в форме восстановления пароля.

**Личный кабинет**

- Переход по клику на «Личный кабинет».
- Переход в конструктор по кнопке «Конструктор» и по логотипу.
- Выход по кнопке «Выход».

**Конструктор**

- Вкладка «Булки» активна по умолчанию.
- Переключение на вкладки «Соусы» и «Начинки».

## Запуск

```bash
python -m pytest -v
```

Тесты запускаются в Google Chrome.
